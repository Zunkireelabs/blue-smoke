### 3.3 `src/features/ble/protocol.ts` — complete, and the highest-risk file

This is the single home for every §4 constant. CLAUDE.md marks it a contested shared file: **append
only, never rewrite existing entries.** Every export carries a comment citing its subsection.

**Constants only. No CMAC implementation, no encoding functions, no I/O.** Encoding is `commands.ts`
in P1-4.0.

All multi-byte integers are **little-endian**. `protocolVersion` for this spec is `0x01`.

**Service and characteristics (§4.2)**

| Const | UUID | Props | Len |
|---|---|---|---|
| Service | `42530001-1E5B-4A9C-9D3F-7C6E1B2A5D80` | — | — |
| C1 `deviceInfo` | `42530002-1E5B-4A9C-9D3F-7C6E1B2A5D80` | Read | 20 B |
| C2 `authChallenge` | `42530003-1E5B-4A9C-9D3F-7C6E1B2A5D80` | Read, Notify | 16 B |
| C3 `authResponse` | `42530004-1E5B-4A9C-9D3F-7C6E1B2A5D80` | Write w/ response | 20 B |
| C4 `lockState` | `42530005-1E5B-4A9C-9D3F-7C6E1B2A5D80` | Read, Notify | 8 B |
| C5 `lockCommand` | `42530006-1E5B-4A9C-9D3F-7C6E1B2A5D80` | Write w/ response | 20 B |
| C6 `commandResult` | `42530007-1E5B-4A9C-9D3F-7C6E1B2A5D80` | Read, Notify | 4 B |

**Advertising (§4.1)** — service UUID in AD type `0x07`; local name `BlueSmoke-XXXX` (last 4 hex of
device UID); manufacturer data 4 bytes `[protocolVersion | stateHint | battery | flags]`. The app
**must** filter scans on the service UUID and must never present arbitrary BLE peripherals.

**`deviceInfo` layout (§4.3)** — offset/len/field:
`0/1 protocolVersion` · `1/1 hwRevision` · `2/2 fwVersion (major,minor)` · `4/12 deviceUid` ·
`16/1 provisioningState` · `17/1 keyGeneration` · `18/2 reserved`

`provisioningState`: `0`=unprovisioned · `1`=provisioned · `2`=activated

**`lockState` layout (§4.4)** — offset/len/field:
`0/1 state` · `1/1 flags` · `2/1 batteryPercent` · `3/1 lastLockReason` ·
`4/2 secondsSinceStateChange` · `6/1 protocolVersion` · `7/1 reserved`

- `state`: `0`=LOCKED · `1`=UNLOCKED · `2`=LOCKED_PENDING_ACTIVATION · `3`=FAULT
- `flags` bits: `0` authenticated session active · `1` charging · `2` low battery (<15%) ·
  `3` dead-man timer armed · `4` session expired
- `batteryPercent`: `0–100`, `0xFF` = unknown
- `lastLockReason`: `0`=user command · `1`=range loss (dead-man) · `2`=session expiry ·
  `3`=power-on default · `4`=fault/watchdog · `5`=revoked
- `secondsSinceStateChange`: uint16, saturates at `0xFFFF`

**Auth handshake (§4.5)** — the constants only:
- Nonce is 16 B, single-use, invalidated after one use or 30 s.
- `proof = AES-128-CMAC(K_sess, 0x01 ‖ protocolVersion ‖ N ‖ session_id[0..3])`, truncated to 16 B.
- Written to C3 as **two frames, order mandatory**: frame 1 `[session_id 16B | keyGeneration 1B |
  reserved 3B]`, frame 2 `[proof 16B | expiresAtDelta 4B uint32]`. An out-of-order frame resets the
  handshake.
- HKDF info string: `"bluesmoke-session-v1"`. Session expiry capped at **90 days**.

**`lockCommand` layout (§4.6)** — `0/1 commandId` · `1/4 counter (uint32, strictly increasing)` ·
`5/7 payload (zero-padded)` · `12/8 tag = first 8 bytes of AES-128-CMAC(K_sess, bytes[0..11])`

| ID | Command | Payload |
|---|---|---|
| `0x01` | `LOCK` | — |
| `0x02` | `UNLOCK` | — |
| `0x03` | `ACTIVATE` | `activationNonce` (4 B) |
| `0x04` | `SET_AUTOLOCK_GRACE` | `graceMs` (uint16), firmware clamps to **1000–30000 ms** |
| `0x05` | `END_SESSION` | — |
| `0x06` | `FACTORY_UNPAIR` | `confirm` (4 B) = `0xDEADBEEF` |
| `0x07` | `PING` | — |

**`commandResult` layout (§4.7)** — `0/1 commandId echoed` · `1/1 resultCode` · `2/2 counter low 16 bits`

| Code | Meaning | | Code | Meaning |
|---|---|---|---|---|
| `0x00` | `OK` | | `0x05` | `SESSION_EXPIRED` |
| `0x01` | `UNAUTHENTICATED` | | `0x06` | `INVALID_PARAM` |
| `0x02` | `AUTH_FAILED` | | `0x07` | `BUSY` |
| `0x03` | `REPLAY` | | `0x08` | `FAULT` |
| `0x04` | `NOT_ACTIVATED` | | `0x09` | `RATE_LIMITED` |

All ten must be representable distinctly. CLAUDE.md forbids a catch-all handler for them.

**Connection parameters (§4.9)** — connection interval 30–50 ms unlocked / 200–400 ms locked-idle ·
slave latency 0 unlocked / 4 idle · **supervision timeout 4000 ms** · ATT MTU default 23 (no MTU
exchange) · PHY 1 Mbps, LE 2M optional.

> **Long Range / S8 coding is deliberately excluded.** Greater range means the device stays unlocked
> further from its owner. Range is a safety parameter on this product, not a feature. Add a comment
> saying so, so nobody "optimises" it back in later.
